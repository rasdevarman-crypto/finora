# Finora

Offline bachelor mess accounting app for Android (Kotlin, Jetpack Compose, Room).

## Features (v0.2)
- Members (add / remove from a month onward)
- Daily meal count per member
- Member deposits (জমা)
- Bazar expenses, divided by total meals (meal rate)
- Fixed monthly costs (rent, bills), divided equally among members
- Per-member monthly summary: deposited, meal cost, share of fixed costs, previous-month carry-over, and final "পাবে / দেবে"
- Every month starts fresh; use ◀ ▶ at the top to browse months. Unsettled balances carry forward automatically.

## Run
Open the folder in Android Studio (Ladybug or newer), let Gradle sync, then Run.
